# AGENTS.md

## Project
Babson Consulting Association website for Mini Project 1.

## Goal
Build a responsive website for the Babson Consulting Association that helps Babson undergraduate students learn about BCA, its consulting programs, resources, events, and ways to connect.

## Design
- Primary color: #065735
- Light green: #dfff9c
- White: #ffffff
- Gray: #f2f2f2
- Brown: #80683f
- Use clean, bold typography
- Follow the layout sketch in the sketch folder
- Keep the design professional, modern, and consistent with BCA branding
- Make the website responsive for desktop and mobile

## Development
- Use semantic HTML
- Use one external CSS stylesheet
- Use CSS Grid and Flexbox for layouts
- Keep navigation consistent across pages
- Use real BCA content
- Keep code organized and readable
